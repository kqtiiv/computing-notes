Graphs	A set of N nodes and A arcs such that each a in A is associated with an unordered pair of nodes<br>G<br>nodes(G)<br>arcs(G)<br><br>SIMPLE: no parallel arcs and no loops

degree of a node	- number of arcs incident on it<br>- the no of arcs which have that node as an endpoint<br>- count loops twice<br>- each arc contribute twice to the sum of degrees<br><br>SO...<br>- the sum of the degrees of all the nodes of a graph is twice the number of arcs, so even<br>- the number of nodes with odd degree is even

Euler path	"a path which uses each arc EXACTLY ONCE<br><br>IF INTERMEDIATE NODE HAS ODD DEGREE, THEN CANNOT USE ALL ARCS<br>IF GRAPH HAS EULER PATH, #ODD NODES = 0/2<br>IF GRAPH HAS EULER CIRCUIT, EVERY NODE MUST BE EVEN"	
Euler circuit/CYCLE	A cycle which uses each arc EXACTLY ONCE	
HAMILTONIAN PATH	A path which visits every node exactly once<br>MUST BE CONNECTED<br>Circuit: path that returns back to start node<br>DEGREE &gt;=2	
Trees	ACYCLIC, CONNECTED, ROOTED (GRAPH G&nbsp; TOGETHER WITH A DISTINGUISED NODE)<br><br>NONROOTED - ACYCLIC CONNECTED<br><br>DEPTH OF TREE IS MAXIMUM DEPTH OF ALL OF ITS NODES<br><br>TREE WITH N NODES = N-1 ARCS	
SPANNING TREES	Non rooted tree T where <br>T is a subgraph of G<br>nodes(T) = nodes(G)<br><br>If G is connected, it MUST have a spanning tree<br>not necessarily unique	
Directed graphs	"Set of nodes N, set of arcs A, such that each arc is associated with an ORDERED pair of nodes<br><br>indegree: #arcs entering x<br>outdegree: #arcs exiting x<br><br>#indegrees = #outdegrees = #arcs<br><br>STRONGLY CONNECTED: for any x, y theres a path from x to y SO require path from both x-&gt;y and y-&gt;x"
